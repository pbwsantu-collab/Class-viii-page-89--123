# 📚 Class 8 English Learning Portal (WB Board)

An interactive, responsive, single-engine web application built to help Class 8 students under the West Bengal Board of Secondary Education (WBBSE) learn, practice, and excel in their English curriculum.

---

## ✨ Features

* 📖 **Interactive Reading Passages:** Every word in selected textbook passages is clickable, instantly displaying:
  * **Part of Speech** (Noun, Verb, Adjective, etc.)
  * **Bengali Pronunciation** (বাংলা উচ্চারণ)
  * **Bengali Meaning** (বাংলা অর্থ)
* ✍️ **Complete Textbook Solutions:** Step-by-step activity answers for lessons covering:
  * **Lesson 10:** *Tales of Childhood* by Roald Dahl
  * **Lesson 11:** *Midnight Express* by Alfred Noyes
  * **End-of-Unit Review Exercises** (Pages 121–123)
* 📝 **Precision Writing Tasks:** High-scoring sample answers for diary entries, letters, and creative writing—strictly crafted within the **90-word limit** using all key points.
* 📱 **Student-Friendly Design:** Modern, colorful CSS theme with responsive navigation, interactive dictionary modals, and smooth scrolling.
* 🚀 **Single Engine (HTML5/CSS3/JavaScript):** Completely self-contained in a single `.html` file—no backend dependencies, libraries, or extra assets required.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structural layout.
* **CSS3:** Custom properties (variables), Flexbox, CSS Grid, and dynamic modal animations.
* **JavaScript (Vanilla):** DOM manipulation, modal popups, and smooth section routing.

---

## 🚀 How to Run

1. Download or copy the code inside `index.html`.
2. Double-click the file to open it in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
3. No local web server or installation required!
